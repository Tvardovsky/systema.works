# systema.works

Landing site for SYSTEMA.WORKS: Next.js (App Router), next-intl (en, sr-ME, ru, uk), plain CSS.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- Copy: `src/messages/*.json`
- Contacts: `src/lib/contacts.ts`
- SEO and JSON-LD: `src/lib/seo.ts`
- Styles: `src/app/globals.css`
